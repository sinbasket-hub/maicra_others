■サーバーについて
Java 版バンのサーバーは人数ニンズウを制限セイゲンしてマルチプレイをしています。最高サイコウ10人ニンまでのユーザーが参加サンカ可能カノウ。
10人ニン以上イジョウとなるとルーター機器キキに大オオきな負荷フカがかかるため不可フカ。
信用シンヨウされたユーザーに限カギり参加サンカを許可キョカしています。ルールを守マモってワールドに接続セツゾクしてください。
【ゲーム動作ドウサ】
あまり正確セイカクにテストプレイはしたことはありませんが、今イマのところラグや落オちたりすることは確認カクニンされていません。人数ニンズウが増フえていくとラグなど多少タショウ起オこる場合バアイがあります。
Windows PC を24時間ジカン稼働カドウさせているため途中トチュウサーバーが落オちたりする可能性カノウセイもあります。
サーバーアプリが落オちることもあります。ワールドに入ハイれなかったときは、その都度ツド教オシえてください。
【災害サイガイ発生ハッセイ】
地震ジシンや台風タイフウなどで停電テイデンになった場合バアイ、ワールドはオフラインとなります。
Java 版バンのワールドとポータルサイトにアクセスできなくなります。また VPN もアクセス不可フカとなるので災害等サイガイトウが発生ハッセイした際サイは Discord へお知シらせします。
